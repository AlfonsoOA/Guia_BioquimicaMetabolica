# Guia_BioquimicaMetabolica
Guía integral de Bioquímica Metabólica (7 temas) para Grado. Incluye resúmenes, figuras originales editables y autoevaluación basada en la Taxonomía de Bloom. Material abierto (.odt, .pptx, .tiff) diseñado para reducir la carga cognitiva y fomentar el aprendizaje activo y la inclusión. Autores: Alfonso Olaya y Lara Sáez. Licencia CC BY 4.0.
